ArtSync is a full-stack MERN application that helps creative professionals — musicians, designers, writers, photographers, filmmakers, illustrators — find collaborators for specific projects, rather than just browsing portfolios like Fiverr or Upwork. Users create a profile, post a project describing what they're building and what skills they need, other users browse and request to join, the owner accepts or rejects, and once accepted, they can chat in real time
